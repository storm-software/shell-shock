`@shell-shock/preset-script` registers the console plugin, the help plugin, and the banner plugin. It is the smaller preset. Use `@shell-shock/preset-cli` when you also want prompts, update, changelog, completions, and skills.

The script preset default options are `--help` (`-h`, `-?`), `--version` (`-v`), and `--verbose`.
