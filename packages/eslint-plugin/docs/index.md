`@shell-shock/eslint-plugin` checks Shell Shock command files. It ships three rules and two flat configs, `base` and `recommended`. Both configs enable the same rules. The plugin name inside ESLint is `shell-shock`.

The rules ignore the `.shell-shock` directory.
