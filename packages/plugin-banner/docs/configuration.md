`plugin` accepts `BannerPluginOptions`.

| Field | Effect |
| --- | --- |
| `title` | Banner title. The theme application title is used when this field is omitted. |
| `theme` | Options forwarded to `@shell-shock/plugin-theme`. |
| `console` | Options forwarded to `@shell-shock/plugin-console`. |

The generator export is `bannerGenerator`.
