`ConsolePluginOptions` extends `ThemePluginOptions` from `@shell-shock/plugin-theme`.

| Field | Effect |
| --- | --- |
| `theme` | `ThemeUserConfig` or other theme plugin options. |

See the theme plugin configuration for `colors`, `borderStyles`, `padding`, `icons`, `labels`, `spinner`, and `settings`.

The generator export is `consoleGenerator`.
