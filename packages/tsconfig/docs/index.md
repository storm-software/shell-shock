`@shell-shock/tsconfig` publishes three TypeScript configs. `base` extends `@powerlines/tsconfig/recommended.json`. `recommended` extends the Shell Shock base. `strict` extends the Shell Shock recommended config.

The source files are `packages/tsconfig/src/base.json`, `recommended.json`, and `strict.json`. The package exports `@shell-shock/tsconfig/base.json`, `recommended.json`, and `strict.json`.
